# Phishing URL Awareness Checker

A lightweight Python command-line educational tool that checks URL text for six warning indicators: `@`, length over 100 characters, IPv4 hostname, five or more hostname labels, `xn--` punycode marker, and HTTP scheme.

## How to run
1. Install Python 3.10 or later.
2. Open a terminal in this folder.
3. Run `python phishing_checker.py`.
4. Enter a URL. Type `q` to quit.

No external packages are required. The program does not open or visit URLs. A result with no warnings does not prove that a URL is safe.

Before submission, run the program on your own computer and replace any example screenshots with genuine screenshots.
